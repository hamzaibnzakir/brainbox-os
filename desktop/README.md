# Brainbox Orb

The desktop shell is an Electron floating orb. It is frameless, transparent, always on top and draggable. Double click expands the shell.

The orb is intentionally only the UI shell. Brainbox OS owns voice, Needle, MCP, permissions, memory and task execution in the Python runtime.

Open source projects researched for interaction patterns include NovaAI, Yumii, Atlas and VOCA. NovaAI and Yumii demonstrate floating voice first orbs, while Atlas demonstrates an orb plus visible task execution. VOCA demonstrates a transparent draggable orb with local voice processing. See the research notes in `docs/ORB_RESEARCH.md`.
